# Ablation 1: No-Prompt Captioning Baseline

This folder contains the no-prompt image-captioning baseline scripts used to
measure model behaviour without structured retrieval context or advanced prompt
engineering.

The evaluated models are:

- InternVL2.5
- Llama 3.2 Vision
- Mistral Small
- NVILA-Lite
- Pixtral
- Qwen3.6
- Qwen3-VL

These scripts are retained because their outputs contribute to the thesis
ablation analysis. They are not used by the selected end-to-end demo.
