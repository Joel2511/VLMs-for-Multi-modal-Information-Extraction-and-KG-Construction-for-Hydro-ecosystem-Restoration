# Archived Captioning HPC Launchers

These Slurm scripts correspond to historical captioning model runs:

- InternVL2.5
- Llama 3.2 Vision
- Mistral Small
- Pixtral
- Qwen3.6
- Qwen3-VL

They are retained to document historical experimental execution. They may
contain machine-specific assumptions and are not the preferred portable entry
points for a new reproduction run.
