# Archived Pipeline 3 Support Scripts

This directory contains historical HPC launchers and metric wrappers retained
for earlier captioning experiments.

They are not part of the selected end-to-end demonstration. Use the active
scripts and HPC launchers outside this archive for the current workflow.

The archived model-specific runners are retained to document historical ablation executions and support the reported thesis results. They have not been refactored into the portable GitHub execution interface; reviewers should use the selected NVILA workflow and documented demo entry points for rerunning the repository.
