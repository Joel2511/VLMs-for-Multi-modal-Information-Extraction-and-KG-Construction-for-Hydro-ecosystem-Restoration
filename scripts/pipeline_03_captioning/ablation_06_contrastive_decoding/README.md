# Ablation 6: Contrastive Decoding

This folder contains contrastive-decoding experiments applied to the selected
NVILA-Lite captioning configuration.

- `run_instruction_contrastive_decoding.py` evaluates instruction contrastive
  decoding.
- `run_visual_contrastive_decoding.py` evaluates visual contrastive decoding.

These scripts are retained for reproduction of the final decoding-level
ablation. They are not used by the standard one-document end-to-end demo.
