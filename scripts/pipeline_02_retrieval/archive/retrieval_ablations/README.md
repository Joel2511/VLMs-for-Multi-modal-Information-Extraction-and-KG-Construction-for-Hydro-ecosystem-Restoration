# Archived Retrieval Ablations

This folder retains the Python implementations of retrieval alternatives
evaluated during model selection:

- `run_clip.py`
- `run_colpali.py`
- `run_colqwen2.py`
- `run_dse_qwen2.py`
- `run_nemotron.py`

The selected retrieval configuration for the final workflow is VDR, implemented
in `../../run_vdr.py`.

These archived scripts are retained for methodological transparency and for
re-executing reported comparisons on suitable HPC infrastructure.
