# Archived Retrieval HPC Launchers

These Slurm scripts correspond to historical retrieval ablation models:

- CLIP
- ColPali
- ColQwen2
- DSE-Qwen2
- Nemotron

They are retained to document the experimental comparisons reported in the
thesis. They are not used by the selected VDR-based end-to-end demonstration.

For the active retrieval workflow, use:

```text
scripts/pipeline_02_retrieval/run_vdr.py
scripts/pipeline_02_retrieval/hpc/run_vdr.sh
```
