# Archived and Exploratory Scripts

This directory contains scripts retained for research traceability but excluded
from the recommended end-to-end workflow.

Examples include:

- Preliminary BLIP, BLIP-2, and Florence experiments.
- Temporary metric scripts.
- Personal or cluster-specific helper scripts.
- Mistaken or incomplete experiments not used in the reported final analysis.

The primary thesis implementation is organized under:

```text
scripts/pipeline_01_extraction/
scripts/pipeline_02_retrieval/
scripts/pipeline_03_captioning/
scripts/pipeline_04_knowledge_graph/
scripts/evaluation/
```

Archived files should not be treated as the recommended reproduction route
unless explicitly documented elsewhere.
